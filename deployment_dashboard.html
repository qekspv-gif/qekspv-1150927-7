GitHub Pages 部署

免費且快速地將自己寫好的靜態網頁（HTML、CSS、JS）發布到網路上。無須複雜指令！

1

建立儲存庫

  • 登入 GitHub 網站。
  • 點擊右上角的 「+」 圖示，選擇 「New repository」。
  • 名稱填入 使用者名稱.github.io (例如：myweb.github.io)。
  • 選擇 「Public」（必須是公開的）。
  • 勾選 「Add a README file」。
  • 點擊下方 「Create repository」。
2

上傳網頁檔案

  • 進入剛才建立好的儲存庫頁面。
  • 點擊 「Add file」 按鈕，選擇 「Upload files」。
  • 將你的網站檔案直接拖曳到頁面中，或點擊選擇檔案。
    *首頁檔名必須命名為 index.html
  • 點擊下方的 「Commit changes」 按鈕完成上傳。
3

啟用與查看

  • 至儲存庫的 Settings > Pages。
  • 設定部署來源 (Source) 為 main 分支與根目錄 (root)。
  • 儲存後等待數分鐘即可。
  • 透過專屬網址造訪你的網站！
詳細操作可參考 feifei.tw

Netlify 拖曳部署

完整 5 步驟：登入、建立新專案、拖曳部署、修改網址，快速上線！

01

登入專案頁面

  • 開啟瀏覽器，進入 Netlify 控制台。
  • 使用帳號（或 GitHub）登入。
  • 點擊左上角的 「Projects」。
02

建立新專案

  • 在右上角，點擊青綠色的 「Add new site」 按鈕。
  • 選擇下拉選單中的 「Deploy manually」（手動部署模式）。
03

拖曳資料夾上傳

Drag and drop your site folder here
  • 將電腦中的網頁資料夾，直接拖曳到中央虛線框內。
  • 等待青綠色的上傳進度條跑完。
04

進入修改網址設定

  • 進入 Project overview 畫面後，點擊左側 「Domain management」。
  • 找到 Custom domains 第一個欄位，點擊右邊 「Options」。
  • 點擊 「Edit site name」。
05

輸入新名稱並上線

  • 刪除亂數英文，輸入想要的網址名稱 (例: my-portfolio-2026)。
  • 點擊 「Save」 (僅限英文小寫、數字與連字號)。
大功告成！網址即刻更新為您的專屬名稱！
